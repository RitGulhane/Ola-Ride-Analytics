# Ola Ride Analytics Dashboard

## Project Overview
This project analyzes Ola ride booking data using Microsoft Excel to uncover booking trends, revenue performance, customer ratings, ride cancellations, and operational insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

## Key KPIs
- Total Bookings
- Total Revenue
- Average Customer Rating
- Cancellation Rate

## Analysis Performed
- Booking Status Analysis
- Revenue Analysis
- Vehicle Type Performance
- Customer Rating Analysis
- Cancellation Trends
- Payment Method Distribution
